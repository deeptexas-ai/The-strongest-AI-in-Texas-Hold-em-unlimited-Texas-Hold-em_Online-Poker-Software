# Deployment Checklist

- Remove secrets, credentials, real online accounts and private datasets before publishing.
- Keep public demos limited to offline simulation, replay analysis and training visualization.
- Verify CFR, equity, range, game-state, replay and test workflows.
- Enable GitHub Pages with GitHub Actions or deploy from `main / docs` if Actions billing is unavailable.
- Submit the sitemap to Google Search Console and Bing Webmaster Tools.
